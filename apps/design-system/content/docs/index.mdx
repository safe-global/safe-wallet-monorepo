Safe UI gives Safe web apps one set of components, tokens and styles. The components are [shadcn/ui](https://ui.shadcn.com/) templates built on [Base UI](https://base-ui.com/), Tailwind CSS v4 and `class-variance-authority`, themed for Safe. The token values come from `@safe-global/theme`, the same source as the mobile app.

## Two ways to use it

<Cards>
  <Card title="npm package" href="/installation/#npm-package">
    Install `@safe-global/ui`, import its stylesheet once and import each component from its own subpath. You get updates
    by upgrading the package.
  </Card>
  <Card title="shadcn registry" href="/installation/#shadcn-registry">
    Run `npx shadcn add @safe/<name>` to copy a component's source into your app, when you need to change it beyond its
    props.
  </Card>
</Cards>

Both come from the same source files in `packages/ui`, so they cannot drift apart.
