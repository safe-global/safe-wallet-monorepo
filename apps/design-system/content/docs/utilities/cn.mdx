## cn

`cn` joins class names with [`clsx`](https://github.com/lukeed/clsx) and resolves Tailwind conflicts with [`tailwind-merge`](https://github.com/dcastil/tailwind-merge), so a later class wins over an earlier one.

```tsx
cn('px-2 py-1', isActive && 'bg-primary', className)
cn('px-2', 'px-4') // 'px-4'
```
