Use the semantic tokens in components (`bg-primary`, `text-muted-foreground`, `border-border`). Each one names a role, not a colour, and has a light and a dark value. The values are generated from `@safe-global/theme`; see [Theming](/theming/) to override one.

Each card shows the variable, the Tailwind utility it maps to, and its raw and resolved value in light and dark mode.
