The theme sets `--font-sans` to DM Sans, so every Tailwind `font-sans` text (the default) uses it. Apps load the font themselves; see [Installation](/installation/).

## Type scale

The [`Typography`](/components/typography/) component holds the Figma type scale. Pick the style with `variant` and the element with `as`, so the visual size and the heading level can differ.
