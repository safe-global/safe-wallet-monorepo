## Usage

<ComponentUsage component="expandable-list" />

Wrap `ExpandableListItem`s in `ExpandableList`, optionally in `ExpandableListGroup`s that each take a `header` such as a status badge. A row takes a `title`, a `leading` icon, a `trailing` node and a `tone` (`critical`, `warning`, `attention`, `success`, `neutral`, `muted`) for its accent bar; its `description` and `children` form the inset body. A row without a body or description has no chevron and does not open. Several rows can be open at once; pass `multiple={false}` to keep one. Stop the click of an interactive `trailing` node from bubbling, or it also toggles the row.

## Accessibility

<BaseUiReference component="expandable-list" />

Each expandable row header is a `role="button"` element with `aria-expanded` and `aria-controls`, wired by the Base UI accordion. Enter and Space toggle the focused row, Tab moves between rows, and the arrow keys move between headers. The tone bar is decorative (`aria-hidden`), so put the status into the title or the leading icon's label as well.
