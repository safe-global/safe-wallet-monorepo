## Usage

<ComponentUsage component="context-menu" />

Wrap the target area in `ContextMenuTrigger` and put `ContextMenuItem`s (and checkbox, radio and sub-menu items) in `ContextMenuContent`. Every action should also be reachable another way, because a context menu is hard to discover.

## Accessibility

<BaseUiReference component="context-menu" />

The menu has `role="menu"`; arrow keys move between items, Enter activates, and Escape closes and returns focus. Keyboard users can open it with the context-menu key or Shift+F10 where the browser supports it.
