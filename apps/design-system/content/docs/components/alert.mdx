## Usage

<ComponentUsage component="alert" />

Pick the tone with `variant` and add `outlined` for a bordered surface. Compose `AlertTitle`, `AlertDescription` and, when the user can act on the message, `AlertAction`. `AlertSeverityIcon` renders the icon that matches the variant.

## Accessibility

<BaseUiReference component="alert" />

`Alert` renders `role="alert"`, so screen readers announce it when it appears. Use it for messages that need attention; for passive hints, plain text is less intrusive.
