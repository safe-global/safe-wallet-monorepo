## Usage

<ComponentUsage component="combobox" />

Compose `ComboboxInput` with `ComboboxContent`, `ComboboxList` and `ComboboxItem`, and show `ComboboxEmpty` when nothing matches. Group options with `ComboboxGroup` and `ComboboxLabel`. It is built on Base UI Autocomplete.

## Accessibility

<BaseUiReference component="combobox" />

The input exposes `role="combobox"` with `aria-expanded` and links to the listbox. Arrow keys move through the options, Enter picks one and Escape closes the list. Give the input a visible label.
