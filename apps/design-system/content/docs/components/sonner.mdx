## Usage

<ComponentUsage component="sonner" />

Render `Toaster` once near the root of the app, then call `toast()` from `sonner` anywhere. It is built on Sonner and takes `theme` as a prop instead of reading a theme library.

## Accessibility

<BaseUiReference component="sonner" />

Toasts are announced through a live region. Do not put the only copy of important information or the only way to undo an action in a toast that disappears. See the [Sonner documentation](https://sonner.emilkowal.ski/).
