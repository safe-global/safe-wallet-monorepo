## Usage

<ComponentUsage component="breadcrumb" />

Build the trail with `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink` and `BreadcrumbSeparator`, and end it with `BreadcrumbPage` for the current page. Collapse long trails with `BreadcrumbEllipsis`.

## Accessibility

<BaseUiReference component="breadcrumb" />

The root is a `nav` labelled "breadcrumb", and `BreadcrumbPage` sets `aria-current="page"`. Separators are hidden from assistive technology.
