## Usage

<ComponentUsage component="switch" />

Pair it with a `Label`. Use `checked`/`onCheckedChange` to control it and `size` for the small variant. For choices that are submitted with a form, a `Checkbox` is often clearer.

## Accessibility

<BaseUiReference component="switch" />

It renders `role="switch"` with `aria-checked` and a hidden native input for forms. Space toggles it. It needs a visible label.
