## Usage

<ComponentUsage component="expandable-card" />

Pass a `summary` (for example stacked avatars and a count) and the details as `children`. It is uncontrolled by default; use `defaultOpen` to start open, or `open` with `onOpenChange` to control it. The details render below the card, not inside it, so each detail can be its own card.

## Accessibility

<BaseUiReference component="expandable-card" />

The whole card is the collapsible trigger: a button with `aria-expanded` that Enter and Space toggle. `detailsLabel` names it for screen readers ("Show recipient details", "Hide recipient details"), so make it describe the details, not the action.
