## Usage

<ComponentUsage component="checkbox" />

Pair it with a `Label` (`htmlFor`) or wrap both in a `Field`. Use `checked`/`onCheckedChange` for a controlled checkbox and `indeterminate` for a parent of a partially selected list.

## Accessibility

<BaseUiReference component="checkbox" />

It renders a button with `role="checkbox"` and `aria-checked`, plus a hidden native input for forms. Space toggles it. It needs a visible label.
