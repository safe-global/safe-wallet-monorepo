## Usage

<ComponentUsage component="button" />

Set the look with `variant` and `size` only, and keep `className` for layout. Use `size="action"` for toolbar and action-bar pills and `size="submit"` for modal submit buttons. Pass `render` to render it as another element, such as a link.

## Accessibility

<BaseUiReference component="button" />

It renders a native `button` with `type` and the disabled state handled by Base UI. Icon-only buttons need an `aria-label`. Use `focusableWhenDisabled` when a disabled button must stay reachable, for example to show a tooltip that explains why.
