## Usage

<ComponentUsage component="sheet" />

Compose `SheetTrigger`, `SheetContent` (with `side`), `SheetHeader` (with `SheetTitle` and `SheetDescription`) and `SheetFooter`. It is a Dialog underneath, so use it for secondary tasks that keep the page in context.

## Accessibility

<BaseUiReference component="sheet" />

It behaves like `Dialog`: focus moves in and is trapped while open, Escape and a backdrop click close it, and focus returns to the trigger. Always include a `SheetTitle`.
