## Usage

<ComponentUsage component="input-otp" />

Compose `InputOTP` with `InputOTPGroup`, `InputOTPSlot` (one per character, each with its `index`) and `InputOTPSeparator`. Set `maxLength` to the code length. It is built on `input-otp`.

## Accessibility

<BaseUiReference component="input-otp" />

A single hidden native input holds the value, so paste, autofill (`autoComplete="one-time-code"`) and screen readers work as with a normal field. See the [input-otp documentation](https://input-otp.rodz.dev/). Give it a label.
