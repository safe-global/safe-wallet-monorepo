## Usage

<ComponentUsage component="stat" />

Pass a `label` and a `value`; `loading` swaps the value for a skeleton of the same height. Use `valueProps` for attributes of the value element, such as a `data-testid`, and the usual div props for the root.

## Accessibility

<BaseUiReference component="stat" />

The value is an `h2`, so a stat can anchor a dashboard section; place it where that level fits the page outline. While `loading`, the skeleton has no text, so announce the loading state elsewhere on the page if it matters.
