## Usage

<ComponentUsage component="peek-collapsible" />

Give it a ref to the last element that should stay visible (`peekUntil`), an `expandLabel` and `open`/`onOpen`: the parent owns `open` and sets it from `onOpen`, so opening is one way. It measures its content with a `ResizeObserver`, animates the height and respects reduced motion. Pass `className` to give the clipped region its surface, for example `rounded-xl bg-card`.

## Accessibility

<BaseUiReference component="peek-collapsible" />

The expand button is a real button, and once open the fade and button become `inert` and `aria-hidden`, so they leave the tab order. The clipped rows stay in the DOM while collapsed, so screen readers can still reach them; give the region an `id` when an outside control also toggles it.
