## Usage

<ComponentUsage component="navigation-menu" />

Compose `NavigationMenuList`, `NavigationMenuItem`, `NavigationMenuTrigger` with `NavigationMenuContent`, and `NavigationMenuLink`. Use it for top-level site navigation, not for app actions.

## Accessibility

<BaseUiReference component="navigation-menu" />

It renders a `nav`. Triggers are buttons with `aria-expanded`; Enter, Space and the arrow keys open panels and move between items, and Escape closes them.
