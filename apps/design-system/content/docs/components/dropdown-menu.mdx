## Usage

<ComponentUsage component="dropdown-menu" />

Put `DropdownMenuItem`s, checkbox and radio items, labels, separators and sub-menus in `DropdownMenuContent`, opened by `DropdownMenuTrigger`. Use it for actions; use `Select` to choose a form value.

## Accessibility

<BaseUiReference component="dropdown-menu" />

The trigger sets `aria-haspopup` and `aria-expanded`. In the menu, arrow keys move between items, typing jumps to a matching item, Enter or Space activates, and Escape closes and returns focus to the trigger.
