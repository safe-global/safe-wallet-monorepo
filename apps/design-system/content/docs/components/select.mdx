## Usage

<ComponentUsage component="select" />

Compose `Select`, `SelectTrigger` (with `SelectValue`), `SelectContent` and `SelectItem`s, grouped with `SelectGroup` and `SelectLabel`. Set the trigger height with `size` to match the controls on the same row.

## Accessibility

<BaseUiReference component="select" />

The trigger is a combobox-style button with `aria-expanded`. Arrow keys move through options, typing jumps to a match, Enter selects and Escape closes. A hidden native input carries the value for forms. Give the select a label.
