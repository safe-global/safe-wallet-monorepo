## Usage

<ComponentUsage component="field" />

Wrap a control in `Field` with `FieldLabel`, `FieldDescription` and `FieldError`. Group fields with `FieldGroup`, or `FieldSet` and `FieldLegend` for related controls. `orientation` switches between stacked and inline layouts.

## Accessibility

<BaseUiReference component="field" />

Connect the label to the control with `htmlFor`/`id`, and reference the description and error from the control with `aria-describedby` so screen readers read them. Use `FieldSet` and `FieldLegend` for radio and checkbox groups.
