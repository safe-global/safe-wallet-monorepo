## Accessibility

<BaseUiReference component="slider" />

Each thumb has `role="slider"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`. Arrow keys change the value by `step`, Page Up/Down by `largeStep`, and Home/End jump to the ends. Give it a label.
