## Usage

<ComponentUsage component="tooltip" />

Wrap the trigger in `TooltipTrigger` and the text in `TooltipContent`; use `TooltipProvider` to share delays. Keep tooltips to a short phrase and never put interactive content in them.

## Accessibility

<BaseUiReference component="tooltip" />

It opens on keyboard focus as well as hover and closes on Escape. The trigger must be focusable, so wrap a disabled button in a focusable element or use `focusableWhenDisabled`. Touch devices have no hover, so do not hide essential information in a tooltip.
