## Usage

<ComponentUsage component="alert-dialog" />

Use it for destructive or irreversible confirmations. Always give it an `AlertDialogTitle` and `AlertDialogDescription`, and put the choices in `AlertDialogFooter` with `AlertDialogCancel` and `AlertDialogAction`.

## Accessibility

<BaseUiReference component="alert-dialog" />

Focus moves into the dialog when it opens, stays trapped inside while it is open and returns to the trigger when it closes. Escape closes it. Unlike `Dialog`, clicking the backdrop does not dismiss it, so the user has to choose. The title and description label the dialog.
