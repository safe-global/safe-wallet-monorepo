## Usage

<ComponentUsage component="input" />

Set the height with `inputSize` and the skin with `variant`; pass `error` to show an error message below the field. For icons or buttons inside the field, use `InputGroup`.

## Accessibility

<BaseUiReference component="input" />

It renders a native `input`. Always give it a label (`Label` with `htmlFor`, or `aria-label`). When `error` is set, make sure the message is announced, for example through `aria-describedby`.
