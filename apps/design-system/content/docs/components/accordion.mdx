## Usage

<ComponentUsage component="accordion" />

Wrap `AccordionItem`s in `Accordion`; each item has an `AccordionTrigger` and an `AccordionContent`. Use it to shorten long pages such as FAQs or settings groups, not to hide primary actions.

## Accessibility

<BaseUiReference component="accordion" />

Each trigger is a button that sets `aria-expanded` and controls its panel. Enter and Space toggle the focused item, and Tab moves between triggers. Arrow-key navigation between triggers is handled by Base UI.
