## Usage

<ComponentUsage component="hover-card" />

Wrap the link in `HoverCardTrigger` and put the preview in `HoverCardContent`. Only use it for supplementary content: anything essential must also be reachable without hovering.

## Accessibility

<BaseUiReference component="hover-card" />

It is built on Base UI Preview Card and also opens on keyboard focus. Touch devices have no hover, so the content must not be the only way to get the information.
