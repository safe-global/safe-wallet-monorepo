## Usage

<ComponentUsage component="chip" />

Set colour with `variant` and geometry with `size` and `shape`. Pass `onDelete` to show a remove button. For read-only status labels, use `Badge` instead.

## Accessibility

<BaseUiReference component="chip" />

When `onDelete` is set, the remove control is a button with its own label. Make sure the chip text is meaningful on its own, since screen readers read it before the remove button.
