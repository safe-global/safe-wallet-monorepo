## Usage

<ComponentUsage component="drawer" />

It is built on Vaul and suits mobile bottom sheets. Compose `DrawerTrigger`, `DrawerContent`, `DrawerHeader` (with `DrawerTitle` and `DrawerDescription`) and `DrawerFooter`. Set the edge with `direction`. For desktop side panels, use `Sheet`.

## Accessibility

<BaseUiReference component="drawer" />

It is a modal dialog: focus is trapped while it is open and Escape closes it. Dragging is a pointer gesture, so keep a visible close button for keyboard and switch users. See the [Vaul documentation](https://vaul.emilkowal.ski/).
