## Usage

<ComponentUsage component="table" />

Compose `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell` and `TableCaption`. Use `TableSortIcon` in sortable headers and `variant="panel"` for a framed table. The table styles live in `table.module.css`, which the registry item copies next to `table.tsx`.

## Accessibility

<BaseUiReference component="table" />

It renders native table elements, so screen readers can navigate by row and column. Use `TableHead` for header cells and add a `TableCaption` that describes the table. Sortable headers should expose `aria-sort`.
