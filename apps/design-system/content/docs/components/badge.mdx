## Usage

<ComponentUsage component="badge" />

Choose the colour with `variant`, the geometry with `size` and `shape`, and use `BadgeDot` for a leading status dot. Keep the text short. Badges are not interactive; use `Chip` or `Button` for something the user can click.

## Accessibility

<BaseUiReference component="badge" />

A badge is plain text. When colour carries the meaning (success, warning), make sure the text says it too, so it does not rely on colour alone.
