## Usage

<ComponentUsage component="dialog" />

Compose `DialogTrigger`, `DialogContent`, `DialogHeader` (with `DialogTitle` and `DialogDescription`) and `DialogFooter`. Width, padding and surface come from the `size`, `padding` and `surface` props. Use `AlertDialog` when the user must choose.

## Accessibility

<BaseUiReference component="dialog" />

Focus moves into the dialog when it opens, is trapped while it is open and returns to the trigger on close. Escape and a click on the backdrop close it. `DialogTitle` and `DialogDescription` label and describe the dialog, so always include a title.
