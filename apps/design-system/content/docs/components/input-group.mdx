## Usage

<ComponentUsage component="input-group" />

Wrap `InputGroupInput` or `InputGroupTextarea` in `InputGroup` and add `InputGroupAddon` (aligned with `align`), `InputGroupText` and `InputGroupButton`. Size and skin are set once on `InputGroup` with `inputSize` and `variant`.

## Accessibility

<BaseUiReference component="input-group" />

The field inside is a native input or textarea and needs its own label. Icon-only `InputGroupButton`s need an `aria-label`.
