## Usage

<ComponentUsage component="resizable" />

Compose `ResizablePanelGroup` (with `orientation`), `ResizablePanel` (with `defaultSize`, `minSize`) and `ResizableHandle` between panels; `withHandle` shows a grip. It is built on react-resizable-panels.
