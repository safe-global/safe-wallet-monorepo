## Usage

<ComponentUsage component="avatar" />

Compose `Avatar` with `AvatarImage` and `AvatarFallback` (initials or an icon shown while the image loads or when it fails). Use `AvatarGroup` and `AvatarGroupCount` for stacks and `AvatarBadge` for a status dot. `size` sets the diameter.

## Accessibility

<BaseUiReference component="avatar" />

Give `AvatarImage` an `alt` that names the person or entity, or an empty `alt` when the name is already shown next to it. The fallback is shown until the image has loaded.
